Trail Ladder: a virtual 100K-steps trail ladder (Zion Riverside Walk, Angels Landing, Half Dome via Mist Trail, Inca Trail). Static single-file web app; steps arrive from an iPhone Shortcut via ntfy.sh. Deploy: connect this repo to Netlify, publish directory '.', no build command.

## Race course

The Race tab is a flat illustrated course drawn in the page: four trail panels (Riverside Walk, Angels Landing, Half Dome, Inca Trail) with a winding path, and pixel-art runners for You (orange), Pace (denim, with a small flag), and Last chance (gray). Names and step counts sit on each runner. The art is original SVG in `index.html`. No third-party models, textures, or map libraries load with this tab.
