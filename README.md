Trail Ladder: a virtual 100K-steps trail ladder (Zion Riverside Walk, Angels Landing, Half Dome via Mist Trail, Inca Trail). Static single-file web app; steps arrive from an iPhone Shortcut via ntfy.sh. Deploy: connect this repo to Netlify, publish directory '.', no build command.

## Race course

The Race tab draws the trails with three.js 0.170.0 from jsDelivr. No API key. The runners are one rigged character, `assets/runner.glb`: Quaternius’s Female Tank Top from the Animated Women pack (February 2019), with that pack’s Run and Idle clips. You wears an orange shirt, Pace is denim blue and is followed by a small flag, and Last chance is a translucent gray copy of the same mesh. Source: https://quaternius.com/packs/animatedwomen.html. License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/).

If WebGL is missing or the model does not load, the Race tab uses the illustrated 2D course instead.
