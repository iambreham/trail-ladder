Trail Ladder: a virtual 100K-steps trail ladder (Zion Riverside Walk, Angels Landing, Half Dome via Mist Trail, Inca Trail). Static single-file web app; steps arrive from an iPhone Shortcut via ntfy.sh. Deploy: connect this repo to Netlify, publish directory '.', no build command.

## Race course

The Race tab draws the trails with three.js 0.170.0 from jsDelivr (MIT). No API key. The 3D stage is `assets/race3d.js`. If WebGL or a model fails to load, the tab keeps the illustrated 2D course.

The four trails sit on real ground. Centerlines are the OpenStreetMap routes from the earlier map tab (ODbL, https://www.openstreetmap.org/copyright). Elevation is baked from AWS Terrain Tiles in terrarium format (https://registry.opendata.aws/terrain-tiles/), which package Mapzen/Joerd public elevation. The grids are `assets/terrain/*.bin` with `courses.json`. Each trail is its own zone. Crossing a boundary fades the fog, sun, and exposure over about half a second. Pace and Last chance can stand in another zone at the same time; the chase camera stays with You, and zones outside the view are culled.

Ground and sky use Poly Haven CC0 textures, resized to 1K WebP, plus one 1K HDRI for image-based lighting and the sky. See `assets/SOURCES.txt`. The renderer uses ACES tone mapping and sRGB output, with fog, a shadow map, and a pixel ratio cap of 2. Zone textures load with the heightmaps and the character; a “Setting the course” bar shows progress.

You, Pace, and Last chance are the same Mixamo woman (`assets/michelle.glb`, the three.js r170 example). Run and Idle are retargeted at load from the Mixamo Soldier clips in `assets/soldier.glb` with `SkeletonUtils.retargetClip`. You wears the orange outfit, Pace is denim and carries a small flag on the right hand, and Last chance is a fresnel ghost of the same mesh. Idle and run crossfade, and the run clip speeds up or slows down with how fast that runner is moving along the course. Mixamo’s license allows using the characters in a project; it does not allow redistributing them as a standalone asset (https://www.mixamo.com/#/license). The three.js examples redistribute these two files (https://github.com/mrdoob/three.js/tree/r170/examples/models/gltf).
